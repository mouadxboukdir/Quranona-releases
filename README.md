# قرآننا — Quranona releases

Installable builds of Quranona (Android). Open the latest release on your phone, tap `quranona.apk` and install it.
After that, the app keeps itself up to date from this page.

نسخ تطبيق قرآننا للتثبيت: افتح آخر إصدار من هاتفك، اضغط على `quranona.apk` وثبّته، وبعدها يتحدّث التطبيق تلقائيًا.
